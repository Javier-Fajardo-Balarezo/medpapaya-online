\# MedPapaya



MedPapaya es una aplicación web agropecuaria para el análisis orientativo de enfermedades en hojas de papaya mediante inteligencia artificial.



El sistema integra dos componentes principales:



1\. Un modelo propio de aprendizaje profundo entrenado para clasificar enfermedades foliares de papaya.

2\. Un módulo de segunda opinión con Gemini para apoyar el análisis cuando el resultado es incierto o cuando el usuario desea una revisión complementaria.



\## Tecnologías utilizadas



\- FastAPI

\- TensorFlow / Keras

\- EfficientNetB0

\- HTML, CSS y JavaScript

\- Docker

\- Gemini API



\## Funciones principales



\- Carga de imágenes de hojas de papaya.

\- Clasificación mediante modelo entrenado.

\- Visualización de confianza y recomendaciones.

\- Segunda opinión con Gemini.

\- Documentación automática con Swagger.



\## Advertencia



Los resultados entregados por MedPapaya son orientativos y no reemplazan la evaluación de un especialista agrícola.
